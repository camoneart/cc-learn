## 4. 非計上 1 件の理由 (#16)

**「`SKILL.md` が 1-3 へポインタを置いていたのに §2 しか読まなかった」= 読んでいない**。
4 つ目の bullet は「**読んだ**装置の警告を、その場で次の 1 手へ当てなかった」= 読んでいることが前提なので当たらない。
1 つ目・2 つ目は測定の話、3 つ目は理由の話でどれも別。
この class を説明するのは `failure-promotion-trigger.md` の **read-miss 原則** (「載せた ≠ 読まれた」/ 2 ホップ目のポインタは辿られない)。
**分母を伏せず、当たらなかったことごと開示する** — 伏せると「11 件全部が既存 bullet に収まった」と読めてしまう。
