## 学び

- **「マージ済み」と「実装済み」は別の日にまたがる。** 8 レーンのうち当日マージまで到達したのは 4 本で、残り 4 本は翌日未明の着地だった。日次で数えるなら commit の author date と PR のマージ時刻の両方を見ないと、その日の実像を取り違える。
