## ゲートの型 (第6波の 2 段構成を踏襲、2 段目の担い手だけ変えた)

1. **1 段目 = fresh reviewer 5 体並列** (1 PR 1 体、code-reviewer 型、名前付き `gate-pr<NNN>`)。判定は全 5 本 **CONDITIONAL / CONDITIONAL GO** (NO-GO 0・捏造 0・縄張り違反 0)。条件正本は各 PR コメント
2. **2 段目 = 別の fresh agent を新規起動** (`gate2-pr<NNN>`)。第6波は「初回担当を SendMessage 再開」だったが、**code-reviewer 型は SendMessage 非搭載**ゆえ再開経路が使えず、1 段目レポートをファイルで渡して読ませる形にした。文脈は失うが、条件が文書化されている限り機能した
3. subagent 運用: 報告は**必ずファイル書き出し**、**回収と同時に TaskStop** (第6波の 6h45m 放置の再発防止。この規律自体が #341 として本波で L1 昇格した)
