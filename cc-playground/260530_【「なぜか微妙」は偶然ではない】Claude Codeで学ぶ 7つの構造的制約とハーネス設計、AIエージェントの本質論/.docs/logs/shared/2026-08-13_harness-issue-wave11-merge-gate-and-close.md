## 本波の重い発見

### 1. Critical — 検査の門番が、自分の緊急スイッチの綴りで自滅する

#402 が新設した「コマンド前置の SKIP 検出」regex が **quoted 領域を潰しきれず、commit message の散文に誤発火して 10 段まるごと無音で exit 0** する。base では deny される入力が PR では approve になる**純粋な退行**。

2 段目が 4 形で `base=DENY / PR=ALLOW` を独立再現。陽性対照 (素の trigger は両方 DENY) と陰性対照 (区切り文字が無い形 / 正常な double quote / heredoc は PR も DENY) つき。

**同じイディオムが base にも在るが、base での用途は「誤検出したら fail-closed (過ブロック)」側。本 PR はそれを「誤検出したら fail-open」の位置へ持ち込んだ。安全性の向きが反転しているのに実装だけが流用されていた。**

処方は同 repo の先例 (`SKIP_GROUNDS_GATE` の「1 行目でも先頭以外は honor しない」) と同型で、レーンは `_CMD_HEAD=${_CMD_NORM%%[;&|\(]*}` による先頭 1 セグメント限定へ直した。

### 2. 「閉じたと主張しているが穴が残っている」型が 4 件

1 段目が 5 本中 4 本で検出したクラス:

- **#402**: #395 の (f) 側 / #337・#319 は **index が空のとき**に無音で通る。**テストが fixture で index を埋めていたから緑になっていた** (false assurance)
- **#396**: 再発防止として足した回帰ロックが、**そのロック自身が起動しない場所**に置かれている
- **#397**: #226 の発見自体は正しく再現できたが、**訂正がドキュメントの葉 1 枚にしか着地せず、実際にチェーンを止める preflight 5 箇所と実行体が旧前提のまま**
- **#400**: ヘッダが宣言した fail-close が実装されておらず、レイアウト変更でも時刻形式変更でも **exit 0 で無言**

### 3. 2 段目が 3 件を OVERSTATED へ格下げした (第10波は覆しゼロ)

**#396-H1**: 機構 (pin が読む 2 ファイルのどちらでも pin は走らない) は 100% 再現。だが結論「誰も赤くならない」は測ると偽 — 4 本目の fork 追加は必ず `scripts/*.sh` を伴い (f) の trigger に載る。実変異で **PASS 364 / FAIL 1**。残る本当の穴は「JSON 単独編集」だけで、**gate の入口で拡張子フィルタに落ちるためどこに pin を置いても塞がらない**。

**#402-②**: 「走査契約テストが赤のまま approve される」は成立しない。**実 (c) を動かすと DENY** (24 秒の実走)。`test-authoring-validators.sh` が `run-all-trigger: skills/*/SKILL.md` を宣言射程に持ち backstop になっていた。2 段目は「approve に至る入力を 1 つも作れなかった」と明記。

**#402-④**: 事実 4 点は CONFIRMED だが「逃げ道は SKIP」は過大 — deny 文言が復旧手順を逐語で名指ししており record へ 2 行足すだけ。

さらに **#402-③ は射程を 1 件縮小**: `~` 前置 dir は PR が閉じていた。**1 段目の probe が実在しないパスを撃っていた**副作用。

- **ゲート側で安く検算できる指摘は自分で撃ち、追認を転記に添える**。ただし**その検算結果を 2 段目へ伝えない** (アンカリング回避)

- **background の「completed」通知はラッパーの終了であってジョブの完了ではない**。プロセスの生死とログの成長で確かめる
