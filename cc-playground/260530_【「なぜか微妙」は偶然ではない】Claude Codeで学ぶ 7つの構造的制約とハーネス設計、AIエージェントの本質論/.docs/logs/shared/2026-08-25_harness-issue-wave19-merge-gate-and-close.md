## 3. 本波の主題 — **実装は壊れず、実装を説明する文が壊れ続けた**

| 面 | 機械が検査しているか |

| 実装 | ✅ テストが守る |
| ソースのヘッダ / 関数コメント | ❌ 誰も見ない |
| PR 本文 | ❌ 誰も見ない (かつ **git 管理外でレビュー中に動く**) |

| 型 | 内容 |

| **(c) 逐語の欠落・改変** | 引用から語が落ちる / commit message が「直した」と書いたのに未適用 |
| **(d) 会計の分母取り違え** | 件数・母数・行数が面ごとに食い違う |
